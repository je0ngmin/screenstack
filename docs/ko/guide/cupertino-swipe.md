# Cupertino 스와이프 뒤로 가기

`CupertinoPageRoute`는 라우트 왼쪽 가장자리 안에서 포인터가 눌리면 움직임 추적을 시작합니다.

## 동작 방식

1. 라우트 왼쪽 가장자리의 `edgeWidth` 영역 안에서 누릅니다.
2. 오른쪽으로 드래그하면 포인터를 따라 현재 페이지가 이동합니다.
3. 거리 임계점을 넘거나 충분한 속도로 놓으면 pop이 완료됩니다.
4. 조건을 충족하지 못하면 라우트가 원래 위치로 돌아갑니다.

가장자리는 브라우저 viewport가 아니라 라우트 요소를 기준으로 계산됩니다. 따라서 다음과 같이
가운데 정렬되거나 너비가 제한된 컨테이너 안에서도 제스처가 동작합니다.

```css
.device {
  margin: 0 auto;
  max-width: 560px;
}
```

## 설정

```tsx
<CupertinoPageRoute edgeWidth={32} swipeBackEnabled>
  <DetailsPage />
</CupertinoPageRoute>
```

| Prop | 기본값 | 설명 |
| --- | --- | --- |
| `edgeWidth` | `24` | 라우트 왼쪽 가장자리에서 제스처가 시작되는 영역의 너비입니다. |
| `swipeBackEnabled` | `true` | 인터랙티브 pop을 활성화하거나 비활성화합니다. |

루트 화면에는 이전 화면이 없으므로 스와이프 뒤로 가기가 자동으로 비활성화됩니다.

드래그 중에는 라우트가 포인터를 선형으로 따라가며, 손을 놓은 후에는 완료 또는 취소
위치로 이동합니다. 덮이는 이전 라우트는 미세한 parallax 효과를 위해 왼쪽으로
이동합니다. 투명한 입력 차단 레이어가 전환과 인터랙티브 스와이프 도중 이전 route와
중첩 스크롤 영역에 입력이 전달되지 않도록 막습니다.
